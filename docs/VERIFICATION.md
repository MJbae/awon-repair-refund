# 구현 검증 기록

검증일: 2026-09-17. Node.js 22 환경.

## 완료한 검증

- 계산·정밀도 30개와 실제 앱 진입점을 사용하는 DOM 통합 테스트 21개, 총 51개 통과.
- 독립 Python Fraction 기대값과 정상 1,641개 사례·45,050개월 행 비교: 불일치 0건. 오류 입력 62개 모두 거부.
- 임시 계산 코드에 오류 9종을 주입하여 테스트가 9종 모두 탐지하는지 확인. 상세 내용은 [계산 정밀도 검증](CALCULATION_AUDIT.md)에 정리.
- 정수·BigInt 유리수 계산: 공급면적 기준 24개월 570,510원, 전유면적 기준 570,526원.
- 연도·월 드롭다운과 고정 기본 연도 2024년, 최초 24개월 자동 입력, 마지막 월 먼저 입력, 기간 역전, 이후 상대편 월 보존.
- 금액 변경 구간도 연·월 드롭다운 사용. 102호 과거 출처 링크와 추가 안내 문단 제거.
- 2024~2026 기본 가정과 24개월 선택의 분리, 변경 구간·개별 월 우선순위와 중복 검사.
- 미래 월·누락 월·0원 구분, 실제액 우선, 소유자 납부 제외, 부분월·윤년, 반환금 초과 처리.
- 호수별 직접 입력과 오류 초안 분리, 접기·펼치기 후 잘못 입력한 금액과 오류 보존.
- 실제 입력액 우선, 14개 호수의 자동 면적별 계산, 예전 저장 면적이 새 매핑을 덮어쓰지 않음.
- 두 상세 카드의 내용 연결, 14호 면적표, ‘법적 근거’ 최하단 접이식 배치, 복사·인쇄·면적 입력 제거.
- 기기 저장·삭제 UI 제거, 저장소 암묵적 읽기·쓰기 없음, 기존 저장값이 결과에 영향을 주지 않음.
- 선택적 에이전트 도구의 등록·정상 입력·잘못된 입력 시 상태 보존을 DOM 테스트에서 검증. 실제 브라우저의 WebMCP 구현과 연동한 검증은 아님.
- 기초 자료의 14세대·면적 합계, 법령 링크 도메인, HTML 자산 연결·중복 ID, JavaScript 문법 검사.
- 배포 파일을 허용 목록으로 구성하여 원본 이미지·로컬 거래 판독표의 포함 방지.
- 로컬 HTTP 서버 정상 응답 및 GitHub 프로젝트 하위 경로 자산 응답 확인.

## 실제 브라우저 검수

이전 작업에서는 브라우저 연결이 불가능했으나 이번 변경 작업에서 Chrome 앱 제어가 가능해져 로컬 화면을 확인했다.

- 호수 선택 시 면적이 옆에 표시되고 입력창이 없는 상태 확인.
- 701호·2024-10~2026-09를 직접 입력하여 자동 24개월과 138,054원 결과 확인.
- 월별 상세를 펼쳐 ‘접기’ 전환, 면적 비율 약 2.05%, 24개 월별 금액·근거 확인.
- 첫 화면과 계산·월별 상세의 데스크톱 스크린샷 확인.

이후 추가한 연·월 드롭다운, 저장 기능 제거, 법적 근거 접기 변경은 DOM 통합 테스트로 검증했다. 모바일 실기기·작은 뷰포트에 대한 별도 육안 검수는 아직 하지 않았다. 반응형 스타일과 좁은 표의 스크롤 안내는 구현되어 있다. 복사·인쇄 기능은 최신 사용자 요청으로 제거했다.
